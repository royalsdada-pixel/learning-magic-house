## 品質與範圍聲明

- 所有已建立題目均為原創練習題，不是出版社試題或課本原文題。
- 國語目前依課名與一般語文能力設計，尚未取得課文、生字、語詞頁逐項校對。
- 數學與自然依家長提供的單元範圍設計，仍需對照實際課本版本、學校進度及老師教法校對。
- 英語、社會、健康與體育、閩南語、藝術尚未收到完整單元範圍，因此保留空題庫並在網站中標示待補，不以其他年級題目代替。
- 每次新增題目需檢查 JSON 格式、題目 ID 唯一性、選項數量與 answer_index 範圍；數學題另需逐題核對計算答案。

## 網站架構

- 五年級題庫保留於 `questions/`。
- 三年級題庫獨立放在 `questions/grade3/`。
- 三年級與五年級分別使用不同 localStorage 存檔鍵，避免 XP、金幣、錯題與紀錄混用。
- 五年級舊存檔鍵 `parkMagicSave` 保持不變；三年級使用 `parkMagicSave_grade3`。
